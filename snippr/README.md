# Snippr Website

Static marketing and legal pages for `snipprapp.com`.

## Pages

- `index.html` - marketing page
- `privacy.html` - privacy policy URL for App Store Connect
- `terms.html` - user agreement / terms URL
- `styles.css` - shared design system

## Local Preview

Open `index.html` directly in a browser. No build step is required.

## Pricing Position

Use `$4.99` as the launch price and `$9.99` as the standard lifetime price.
This keeps the anti-subscription wedge while avoiding a permanent race-to-the-bottom anchor.
